# Зов Земли · первая экспедиция

Образовательный сайт для 6 класса: межпредметный проект по физике и информатике с роботом ЛУМОЙ. Первая станция — «Туманное поле / Сообщение сквозь туман».

## Запуск

Сборка, npm и внешние сервисы не нужны. Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте адрес сервера в браузере. Для ES-модулей нужен HTTP-сервер; открытие `index.html` через `file://` не поддерживается.

## Главная

- Настоящая процедурная 3D-модель ЛУМЫ и исследовательского острова.
- Поворот головы и лёгкое движение сцены вслед за курсором.
- Карта пяти станций, вход в миссию, команда, атлас и памятка учителю.
- Уменьшение декоративной анимации при системной настройке reduced motion.

## Первый этап

1. **Задача.** Сюжет, цель, роли и название команды.
2. **Сигнал.** Интерактивный декодер шифра Цезаря. Алфавит без «Ё»; `ПГУЫУЦХ → МАРШРУТ`, сдвиг при чтении −3.
3. **3D-лаборатория.** Две тележки на одинаковых 12-метровых дорожках, одновременный старт, скорости от 1 до 4 м/с. До запуска нужен прогноз. Доступны вращение камеры, приближение, три вида, туман, пауза и возврат на старт. Журнал заполняется после завершения опыта. Для продолжения нужны минимум два разных исхода.
4. **Проверка.** Сопоставление сценарного обобщения с собственным контрпримером, объяснение и составление алгоритма исследования.
5. **Атлас.** Выбор для конкретных последних настроек, вывод, рефлексия командной работы, сохранение и выгрузка в TXT/JSON. Объяснение можно явно обновить после новых опытов.

Прогноз не обязан совпасть с результатом. Неподтвердившееся предположение рассматривается как повод пересмотреть объяснение.

## Физическая модель

Равномерное прямолинейное движение: `x(t) = min(v·t, s)`, `t_finish = s/v`. Путь обеих тележек одинаков — 12 м; они стартуют одновременно. Сопротивление и разгон не учитываются. Это наблюдения в цифровой модели, а не реальные измерения природы. Формула не требуется от ученика для прохождения; смысл м/с объясняется в интерфейсе.

Если WebGL недоступен или потерян контекст, пользователь получает явную плоскую модель с теми же условиями. При потере контекста незавершённый опыт отменяется. Движение в опыте не пропускается при reduced motion. При скрытии вкладки активный опыт ставится на паузу; прокрутка за пределы сцены не останавливает физику.

## Данные и ограничения

Черновик, опыты и итоговая запись хранятся только в localStorage текущего браузера. Названия и записи не отправляются на сервер. Для передачи результата учителю используется выгрузка. При недоступности localStorage можно пройти миссию в текущей вкладке и скачать итог. Запись старого прототипа `zov-zemli-v1` не удаляется.

**Подключённой нейросети нет:** проверяемая версия на шаге 4 — явно обозначенная сценарная реплика. Автоматического измерения или оценивания 4К нет; ответы и ход работы дают материал для педагогического наблюдения. Четыре остальные станции пока представлены картой. Физическое содержание требуется согласовать с автором физической части ВКР до апробации.

## Файлы

- `index.html` — главная и оболочка миссии.
- `app.js` — маршрут, задания, журнал, сохранение и выгрузка.
- `scene.js` — процедурные модели, камера и анимация движения.
- `styles.css` — адаптивное оформление и доступность.
- `assets/vendor/three.module.min.js` — закреплённая локальная Three.js 0.164.1; рядом лицензия MIT и сведения об источнике/целостности.
- `assets/concept.png` — исходный визуальный эскиз; используется только как запасная иллюстрация.

Three.js получена из официального npm-реестра; SHA-512 архива проверен по метаданным пакета. В работе сайт не обращается к CDN, API или внешним моделям.

## Проверка реализации

Полное прохождение проверено в Chromium через Playwright с настоящим WebGL-рендерингом (SwiftShader в облачной среде). Пройдены 12 групп проверок: реакция главной на курсор; шифр и блокировка следующих шагов; движение, пауза, обратный исход и равенство; окно команды и отмена опыта; контрпример и алгоритм; атлас, повторное открытие, редактирование и TXT/JSON; отсутствие внешних запросов; мобильная эмуляция 390/320 px; работа плоской модели без WebGL; восстановление повреждённого черновика; reduced motion; отсутствие необработанных ошибок JavaScript. Проверка мобильной вёрстки выполнена в эмуляции, не на физических телефонах.
