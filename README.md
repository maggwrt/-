# Зов Земли

Прототип образовательного сайта для 6 класса: межпредметный проект по физике и информатике с роботом ЛУМОЙ.

## Запуск

Зависимости и сборка не нужны. Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте в браузере адрес запущенного сервера. Можно также открыть `index.html` напрямую, однако сохранение данных для `file://` зависит от браузера.

## Что работает

- Главный экран, карта, разделы «Команда», «Атлас», «Для учителя».
- Первая демонстрационная миссия: шифр Цезаря и качественное сравнение движения.
- Сохранение названия команды и одной записи атласа в localStorage, выгрузка записи в TXT.
- Адаптивная вёрстка, клавиатурная навигация, поддержка уменьшенного движения.

## Ограничения

Четыре станции пока представлены заглушками. Нейросеть, серверное хранение, учётные записи, аналитика и оценивание 4К не подключены. Физические задания предварительные и должны быть согласованы с автором физической части проекта. Данные доступны только в том браузере, где их сохранили.

`assets/concept.png` — сгенерированный визуальный эскиз, включая иллюстрацию ЛУМЫ. Код страницы написан отдельно; кнопки и задания реализованы в HTML/CSS/JavaScript.

## Публикация

Размещение файлов в репозитории само по себе не публикует сайт. Для GitHub Pages в настройках репозитория выберите **Pages → Deploy from a branch → main → / (root)**. Доступность Pages зависит от настроек аккаунта и видимости репозитория. Сайт не обращается к внешним API и использует относительные пути, поэтому работает и в подпапке проекта.
